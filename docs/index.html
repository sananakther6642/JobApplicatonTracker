Features

Everything you need to land your next job

A complete toolkit for managing your job search — from the first application to the final offer.

📋

Track Applications

Log every application with company, role, status, source, applied date, and custom notes. Filter, sort, search, and star your most important applications.

📊

Stats & Charts

Visualize your pipeline with a response-rate heatmap, funnel chart, day-of-week breakdown, and source analytics. Know what's working.

✨

AI Job Generation

Paste any job description and auto-fill all fields using AI. Upload your CV PDF to get a tailored analysis and pre-populated form.

💌

Email Templates

Ready-to-use templates for follow-ups, thank-you notes, offer negotiations, and polite rejections. Pre-fill with job details in one click.

💵

Salary Comparison

Compare salary ranges across all your applications and offers. Side-by-side offer comparison helps you choose the right role confidently.

✅

Interview Checklists

Per-job prep checklists with seeded defaults: research, questions to ask, tech setup, portfolio links. Track your interview rounds and outcomes.

👥

Multi-User Accounts

Register multiple user accounts — each user sees only their own data. Session-based authentication with secure password hashing.

📄

CSV Import & Export

Bulk-import jobs from any CSV and export your full pipeline at any time. Keeps you independent of the tool.

👤

Contact Book

Auto-sync recruiters and hiring managers from job entries. Search, edit, and manage your professional network alongside your applications.

Get Started

Up and running in 2 minutes

JAT runs entirely on your machine. No cloud account, no signup, no data leaving your computer.

  1. 1

    Clone the repository

    Download the source code from GitHub to your local machine.

  2. 2

    Install dependencies

    Install Flask and Flask-Login — the only two Python packages required.

  3. 3

    Run the app

    Start the development server. The SQLite database is created automatically on first run.

  4. 4

    Create your account

    Open your browser to http://localhost:5050, register an account, and start tracking.

Terminal

# 1. Clone
git clone https://github.com/yourusername/JAT.git
cd JAT

# 2. Install dependencies
pip install flask flask-login

# 3. Run the server
python app.py

# 4. Open in your browser
http://localhost:5050
ⓘ Requirements
  • ✓ Python 3.8+
  • ✓ Flask
  • ✓ Flask-Login
  • ✓ SQLite (built into Python)
  • ✓ No internet connection needed
